# Yat dans les noms ekaviens : décision

**Décision du 2026-10-25 (ADR 2026-10-25-ekavien-sans-yat.md) : les noms ekaviens n'ont pas
de yat et gardent *e*.**

> « Les noms ekaviens n'ont pas de yat donc pas besoin de e háček. »

- Le yat (ě) n'est restauré que là où la forme officielle montre le réflexe ijekavien : Rěka,
  Běļina, Bělo Poļe, Bělovar, Osěk, Široki Brěg, Sěnica, Prěpoļe, Plěvļa, Han Pěsak, Němci.
- **Les noms ekaviens gardent *e*** :
  - en serbe et en slovène : Beli Manastir, Sremska Mitrovica, Bela Palanka, Leskovac,
    Brežice, Novo mesto ;
  - en bulgare : Bjala, Červen Brjag, Belogradčik. Le réflexe *ja* y reste écrit *ja*.
- La liste de racines proposée le 2026-10-24 (běl-, brěg-, lěsk-, měst-, rěk-…) est
  abandonnée.

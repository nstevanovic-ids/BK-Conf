## Changements v3 vs v1

- **ě restauré** (jat' illyrien, prononciation dialectale libre : e/je/ije/i/ja)
- **ñ remplace ń** pour /ɲ/ (précédent hispano-méditerranéen + kazakh ; accessibilité AZERTY)
- **ļ remplace ĺ** pour /ʎ/ (tradition cédille balte ; symétrie visuelle avec ñ)
- **ç éliminé** (réservé aux noms propres albanais/turcs ; ne compte pas dans les 32)
- **dz** redevient séquence d+z
- Conservés : x /dʒ/, ã schwa bulgare, ć/đ, š/ž/č

## Règle toponymique v3

- Référence cyrillique avec **њ** → **ñ**
- Référence cyrillique avec **љ** → **ļ**
- Sinon : graphie latine inchangée
- **Beograd** : exception déclarée
